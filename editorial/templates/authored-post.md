# Рабочий заголовок

## Сведения

- Дата получения: …
- Карточка: … / без карточки.
- Происхождение: авторский / авторский с правкой агента / смешанный /
  генерация агента / не уточнено.
- Для образцов стиля: да для переданного собственного поста / нет по просьбе
  автора / не уточнено при неизвестном или смешанном происхождении.
- Публикации: ссылки и фактические даты / пока не опубликовано.
- Для сайта: не рассматривали / кандидат / нужна переработка / размещён.

## Текст автора

Сохранить исходные формулировки. Если получена отдельная новая версия,
сохранить её с пометкой версии, а не терять предыдущую.

## Заметки отдельно от текста

При необходимости: иллюстрации, фактические уточнения, варианты для сайта,
ссылка на предложенные правки. Заметки не считать образцом авторского стиля.
