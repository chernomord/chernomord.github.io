# Авторские тексты

Сюда можно класть написанные посты до и после публикации. Здесь хранятся
разборы, связанные с основным планом, и тексты на злобу дня через продуктовую
оптику. Первый сохранённый образец — [Corporate chirp](2026-11-15__corporate-chirp__v001.md).

## Как добавить

Один Markdown-файл на текст: `YYYY-MM-DD__short-title__v001.md`.
Изображения — при необходимости в соседней папке `short-title/`.
Можно воспользоваться [шаблоном](../templates/authored-post.md) или просто
прислать текст в чат с просьбой сохранить.

Полезно знать происхождение текста, связь с карточкой и опубликованную версию.
Переданный пользователем собственный пост можно анализировать для накопления
стиля по текущему поручению. Если образец нужно исключить, достаточно пометки.
Неизвестные сведения оставляем неуточнёнными. Уже состоявшаяся публикация
не обязательна для хранения.

## Два применения

**Для сайта:** отдельно оценить законченность мысли, факты и нужную адаптацию.
Затем следовать [контрактам блога](../../governance/blog/operation-contracts.md).
Не копировать автоматически в `content/` и не выбирать тип по длине текста.

**Для стиля:** брать собственные тексты автора, не исключённые им, отделяя основной
текст от цитат, метаданных и редакторских замечаний. Свойства описывать
с примерами; единичный приём не объявлять постоянным правилом.

При запросе «отредактируй» сохранять исходник. При запросе «сохрани» не
переписывать текст под редакционный шаблон. [Заметки о стиле](../style-notes.md)
пока содержат пожелания и ссылку на первый образец.
