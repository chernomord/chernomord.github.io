# P09. Когда простой формы достаточно

Готовность: заготовка. Угол: граница подхода. Связи: T08; F00, F14; контрпример P01.

**Адресат:** владелец задачи, выбирающий объём инструмента.
**Вопрос:** когда дополнительная модель создаёт работу без нужной пользы?
**Функция:** показать границу собственного подхода и основания ограничения объёма.

## Пояснение для автора

Тебе прислали координаты точки встречи. Задача — открыть эту точку на карте.
Представь, что сервис требует сперва восстановить по координатам город,
улицу и номер дома. Вся работа по получению точного места уже сделана.
Зачем заставлять человека заново собирать сведения, нужные для другого входа?

## Реальный пример

Google Maps принимает в строке поиска широту и долготу и показывает точку.
Это готовый путь для человека, у которого уже есть координаты. Если вместо
них есть задача выбрать подходящее место встречи, карта с вариантами и
маршрутами помогает по-другому. Для P09 можно вернуться к сцене из P01.
Если расчётные числа уже подготовлены, простой ввод может быть удобнее.
Если состав ещё меняется, работа с линиями даёт возможность проверить изменения. [Поиск по координатам в Google Maps](https://support.google.com/maps/answer/18539?hl=en)

## Материал

- Учебная ситуация: специалист получает уже подготовленные значения из
  другого процесса и хочет проверить одно соотношение.
- Если заставить его сначала воссоздать структуру, из которой получены числа,
  появится лишний этап. Возможно, достаточно нескольких полей и понятного результата.
- Сопоставить с ситуацией P01: там человек ещё собирает состав и исследует изменения.
- Выбор зависит от исходных материалов и следующего действия; «более богатая
  модель» не является самостоятельной целью.

**Возражение:** происхождение величин иногда нужно сохранить для проверки
или последующего изменения; это может оправдать дополнительную структуру.
Если после ответа предстоит двигать отдельные части сценария, тот же быстрый
вход может решить только первую часть задачи.

## Фразы и кадр

- «— Вот координаты. — А какой адрес?» Человек держит листок с точкой на карте,
  а на стойке перед ним обязательные поля «Город», «Улица», «Дом». Сцена вымышлена.
  В кадре должна быть очевидна цель — найти уже известное место.
- «Мне эту точку открыть». Рука кладёт карточку с координатами рядом с картой,
  на которой уже есть одна метка. Сдержанный кадр для варианта поста про пользу
  короткого пути, когда исходные сведения уже подготовлены.

## Опоры и подготовка

[NHS: контекст задачи](https://service-manual.nhs.uk/content/how-to-write-good-questions-for-forms/understand-the-problem-before-you-write-your-questions)
— основание выяснять исходную ситуацию, а не копировать прежний удачный выбор.
Сравнение форм — наше рассуждение на учебных сценариях, без измерений эффективности.

До написания: назвать источник готовых величин и что специалист собирается
сделать с ответом. Проверить, не требуется ли ему всё-таки менять состав.
