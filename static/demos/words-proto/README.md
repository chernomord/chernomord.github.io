# Ontology Switching Lab

This is a minimal pre-alpha demo for the "world as representation" idea.
It keeps only the moving text anchor, transformation controls, reading phase,
and a tiny diagnostic line.

It is intentionally separate from `simulation/`, which remains the math
visualization workspace for the toy models.

Graphical demo branches live under [visual/](./visual/). Keep this root demo
text-first unless a branch is explicitly moved into the visual workspace.

## What This Demo Shows

- one large central text attractor;
- transformation toggles;
- a continuous reading phase slider;
- a minimal diagnostic layer.

## Files

- `index.html`: demo shell
- `app.js`: prototype logic
- `styles.css`: presentation layer

## Status

This is a pre-alpha implementation workspace, not the source of truth for the
model.
