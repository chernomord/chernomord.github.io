# Локальный governance блога

Этот каталог — источник решений о структуре блога. Он не является редакционным
планом и не предписывает темы или периодичность публикаций.

Порядок приоритета:

1. [Алгебраическая модель](algebraic-model.md).
2. [Инварианты](invariants.md).
3. [Явные не-цели](non-goals.md).
4. ADR в каталоге [`adr/`](adr/).
5. [Контракты операций и проекции в сайт](operation-contracts.md).

Любое изменение смысла сущности, отношения или порога продвижения сначала
оформляется ADR, затем меняет модель, инварианты и контракт реализации. Не
нужно менять шаблоны сайта, чтобы неявно поменять смысл модели.

## Принцип

Блог фиксирует траектории работы, а не заранее выбранную предметную нишу.
Темы могут быть нерегулярными. Их видимость возникает из опубликованных
связей, а не из заранее созданных пустых рубрик.
